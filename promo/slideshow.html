In-chat commands

Control it like a CLI.

wechat-agent
/sessions  list conversations
/use 2     switch session
/new      start fresh
/stop      cancel
/yes /no   approve · deny
Safe by default

No strangers.
No surprise actions.

Hard allowlist — non-allowlisted senders are never fed to the model.
Credentials via the DSH credentials service — never in config.
Every risky action needs your /yes — timeout defaults to deny.
Get it — one command
terminal
$ git clone https://github.com/PRTS168/dsh-wechat-suite
$ dsh plugin --profile web add ./dsh-wechat-suite

Then scan the QR once. Done.
