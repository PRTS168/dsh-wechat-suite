## dsh-chatnode-wechat v0.2.0

自 v0.1.0 以来的改进。

### 新功能
- **入站用户消息附带发送时间戳**：喂给 AI 的内容统一加 `[发送于 YYYY-MM-DD HH:mm]` 前缀（文字/图片 OCR/语音 STT/文件/视频全部生效）
- **双向文件与视频**
  - 入站 file/video 自动下载解密并落盘 `mediaDir`，以 `[微信文件]` / `[微信视频]` 带路径引用交给 agent（保留原名，失败有明确提示）
  - 出站新增 agent 工具 `wechat_send_file` / `wechat_send_video`（视频以可播放 mp4 附件送达，iLink 无原生视频气泡）
- **接通 `/perm`**：两步切换权限预设命令（此前机制就绪但无命令入口）
- **一键配置向导 `scripts/setup.mjs`**：`pnpm setup`（交互）或 `--yes --set key=value`（非交互，支持 `--dry-run`）；`siliconflowKey` 一键填充 OCR/生图/STT/TTS 四把 key；只改 profile 中 `dsh-chatnode-wechat` 配置块、自动备份

### 其它
- 单元测试 **65 项全绿**（gateway 18 / node 24 / markdown 9 / morning 6 / picker 4 / reminders 4），可离线运行（fake iLink 服务器）
- 新增：入站文件/视频用例、发送时间戳断言
- README 双语同步（/perm、pnpm setup、填写点说明）；版本号 0.2.0

### 注意
仅供参考，已在一套环境实测（2026-09）；配置需按 README / `pnpm setup` 自行填入（`allowFrom`、`WEIXIN_*` 凭据、SiliconFlow `sk-`、`ttsVoice` 等）。
