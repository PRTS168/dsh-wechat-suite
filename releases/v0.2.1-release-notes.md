## dsh-wechat-suite v0.2.1

自 v0.2.0 以来的改进。

### 新增

- **Web 管理页「微信桥配置」**（设置 → 插件 → 微信桥配置）：在一个页面里管理全部占位待填项
  - 必填：微信白名单 ID、人设 preset 名、聊天模型 provider / 模型
  - 可选：cwd、mediaDir、reminderFile、morningFile、esp32BaseUrl、心跳间隔、审批超时、单条上限、分块间隔
  - 媒体模型：OCR / 生图 / STT / TTS 的 Key、模型、目录与克隆音色 uri
  - 密钥脱敏显示；留空 = 不修改，输入 `-` = 清除；保存直接改写 profile 的 `cordis.patch.yml`（自动备份、保留注释与其他插件行）
- **人设设置**：列出 agent preset，在线编辑人设正文（仅替换 `agent.cordis.yml` 的 persona 段，自动备份），并支持「复制为新 preset」快速派生第二个人设
- **主机 API** `/dsh-chatnode-wechat/api`：`GET /schema` `/config` `/status` `/presets` `/persona`，`POST /save` `/persona` `/preset/copy`
  - 全部请求必须携带自定义头 `X-DSH-Chatnode-Wechat: 1`（跨站无法伪造）
  - 第二个 bundle 行 `dsh-chatnode-wechat/config-api` 只在存在 `webServer` 的 profile 中加载，headless 不受影响

### 其它

- 依赖对齐 DSH **0.1.1-rc.2**（原 0.1.0-rc.6），typecheck / build 全过
- 单元测试 **65 → 72 项**（新增配置读写、备份、密钥脱敏用例）
- README 中英同步：Web 管理页与人设使用说明

### 注意

仅供参考，已在一套环境实测（2026-09）。保存配置或人设后需重启 dsh web 生效；`WEIXIN_*` 凭据仍需先 `pnpm login` 扫码写入。
